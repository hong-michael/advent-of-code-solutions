# advent-of-code-solutions
My personal solutions to [Advent of Code](https://adventofcode.com/) puzzles, organized by year and day.

## Structure

```
<year>/
  dayXX/
    <solution>.py
```

Each script reads its puzzle input from `input.txt` in the current directory, so run it from inside its day folder:

```bash
cd 2023/day01
python calibration_sum.py
```
